# EDA with Python

Notebooks and datasets from a hands-on course on exploratory data analysis (EDA), data wrangling, preprocessing, and feature engineering with Python — covering pandas, statistics, visualization, and an introduction to Gen AI tools for data analysis.

Each module is self-contained: the datasets each lesson reads from live alongside the notebooks in the same folder.

## Module 2 — Data Wrangling with Python

Getting comfortable with pandas: reading data, building and indexing DataFrames, querying and grouping columns, working with dates, and combining data from multiple sources.

- Lesson 1 — Getting started with a dataset (reading CSV/Excel with pandas)
- Lesson 2 — DataFrame fundamentals and indexing
- Lesson 3 — Exploring and querying columns
- Lesson 4 — Manipulation and grouping of data
- Lesson 5 — Date-time operations in Python
- Lesson 6 — Putting together data from multiple sources (merge/join/concat)

**Data:** `POS_Data.csv`, `POS_CleanData.csv`, `Online Data.xlsx`

## Module 3 — Exploratory Data Analysis

Descriptive statistics, common data distributions (binomial, etc.), relationships between features (correlation), better data visualizations, and hypothesis testing.

- Lesson 1 — Descriptive statistics
- Lesson 2 — Understanding data distributions
- Lesson 3 — Relationships between features
- Lesson 4 — Enhancing data visualizations
- Lesson 5 — Comparing two groups: hypothesis testing

**Data:** `POS_CleanData.csv`, `CreditCardData.xlsx`, `ProbDist_Data.xlsx`

## Module 4 — Data Preprocessing

Cleaning and preparing raw data: handling missing values, transforming categorical/numerical features (binning, encoding), normalization, and outlier detection.

- Lesson 1 — Treating missing values
- Lesson 2 — Data transformation (categorical features, binning)
- Lesson 3 — Data normalization and outlier detection

**Data:** `POS_Data.csv`, `Online_Data.csv`

## Module 5 — Feature Engineering

Dimensionality reduction techniques, and an introduction to using Generative AI / LLM tools (PandasAI) for data analysis.

- Lesson 1 — Reducing the dimensionality of datasets
- Lesson 2 — Gen AI in Python (introduction to PandasAI for data analysis)

**Data:** `Obesity_data.csv`, `POS_Data.csv`

## Tech Stack

Python, pandas, NumPy, Matplotlib/Seaborn, SciPy (statistics), PandasAI.

## Status

Coursework/practice notebooks, kept as a reference for EDA and data preprocessing workflows in Python.
